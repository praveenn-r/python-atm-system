# ATM CLI

A simple interactive ATM simulator written in Python.

## Features
- Check balance
- Deposit money
- Withdraw money
- Change PIN
- Mini statement history

## Prerequisites
- Python 3.8 or newer

## Usage
Run the script and follow the prompts:

```bash
python atm.py
```

Default PIN: `1234`

This is an interactive command-line program — enter choices and amounts when prompted.
